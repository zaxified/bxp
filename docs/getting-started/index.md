# Getting started

Three pages, in order. Each one ends where the next begins, so the whole
section reads as a single sitting — from a downloaded archive to a converted
file.

- [Install](install.md) — download the console archive or the desktop app,
  verify the checksum, and check that the binary runs.
- [First conversion](first-conversion.md) — point a shipped template at an
  export file and read the result. No template authoring yet.
- [Built-in templates](built-in-templates.md) — what ships next to the binary,
  what each one converts, and how to run one by id.

If your source is not in that last list, the [Guide](../guide/templates.md)
covers writing a template for it — that is the point where BXP stops being a
converter you run and becomes one you configure.
