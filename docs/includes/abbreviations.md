*[BXP]: Broker eXchange Parser — converts broker exports to tracker CSV
*[MCP]: Model Context Protocol — JSON-RPC tool surface for AI agents
*[JSON5]: JSON with comments, unquoted keys, and trailing commas
*[CSV]: Comma-Separated Values (RFC 4180)
*[XLSX]: Excel spreadsheet (ZIP of XML parts)
*[AST]: Abstract Syntax Tree — the parsed config structure the GUI edits
*[FFI]: Foreign Function Interface — the C-ABI bridge between Dart and Zig
*[pre_pass]: First pass that builds a lookup table for cross-row joins
*[row_rules]: Ordered routing list; first matching rule decides the output
*[input_schema]: Per-row $variable definitions evaluated from input columns
*[output_schema]: Output CSV header to $variable mapping; sets column order
*[LOOKUP]: Retrieve a value stored by pre_pass under a key and field name
*[REMAP]: Whole-value lookup against a named or inline map
*[DATE_CONVERT]: Parse a date with one token format and emit it in another
*[bxp-cli]: The conversion engine binary
*[bxp-mcp]: The stdio MCP server exposing bxp's stateless surface
*[bxp-gui]: The Flutter desktop application
*[csvx]: BXP output file suffix — a tracker-ready CSV
